# Quiet Chess

Slow down. Think ahead. Make your next move.

Chess arcade game. You play White against a casual computer opponent, or choose Pass & play for two people. Tap a piece, then a highlighted square. Castling, en passant and promotion are supported.

## Play and host

Double-click index.html to play locally after extracting the ZIP. The game is bundled into that file and does not require a local server. For GitHub Pages, enable Settings → Pages → GitHub Actions. The included workflow publishes the standalone game.

Expected URL after deployment: https://kofidon99.github.io/quiet-chess/
